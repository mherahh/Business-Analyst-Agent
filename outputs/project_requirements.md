# Product Requirements Document (PRD): Campus Connect

## Executive Summary & Project Overview

- **What is the name of your project?**: Campus Connect
- **Describe the project and what it should do.**: Campus event management platform where students can discover, organize and register for events
- **What type of website is it?**: Other
- **Who will use it? (e.g. customers, admin)**: Universtiy Students
- **List the main features you need (comma separated).**: User registration/login page, Browse and search events, create/manage events, admin dashboard, email notifications, reccomendations for events
- **Which of those features are must-have for the first launch?**: User registration and login, browse and search events, event registration
- **Any outside services needed? (payments, email, maps...)**: Email notifications | Users should be notified when the event is approaching, capacity being filled of an event , remidner
- **Any technology or framework preference? (e.g. Django)**: React for frontend
- **Any budget or deadline limits?**: 10k with 1 month deadline

## Brand & Visual Identity

- Theme Preset: Ocean Blue
- Primary Color: #1E6FD9
- Background Color: #F5F9FF

## Product Objectives

- Enhance student engagement by providing a centralized platform for event discovery and registration.
- Streamline event management processes for students and administrators.
- Facilitate communication and notifications regarding events to improve attendance.
- Create a user-friendly interface that encourages regular use among university students.
- Establish a scalable platform that can accommodate future enhancements and increased user load.

## Core Functional Scope

- FR-01: User registration and login functionality.
- FR-02: Ability to browse and search for events based on various criteria.
- FR-03: Functionality for users to create and manage events.
- FR-04: Admin dashboard for managing events and users.
- FR-05: Email notifications for event reminders and updates.
- FR-06: Recommendations for events based on user preferences.
- FR-07: Event registration functionality for users.

## MVP Boundaries

- User registration and login
- Browse and search events
- Event registration
- Email notifications
